# 🧩 Sudoku Solver – Web Project

This project is a **web-based Sudoku game and solver** built using only **HTML, CSS, and JavaScript**. It features multiple interactive pages, such as the main menu, loading screen, settings, game interface, and more. The aim is to deliver a smooth and enjoyable Sudoku-playing experience directly in the browser.

---

## 📁 Included Files

- `index.html` – Main home/start page of the game
- `suduku game.html` – The actual Sudoku game board and logic
- `settings.html` – Page to customize settings like difficulty, sound, or theme
- `loding.html` – A loading animation or splash screen before the game starts
- `about.html` – Information about the game or the developer
- `exit.html` – Exit or game-over screen
- `download.png` – Download icon or image used within the project
